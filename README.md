# 🌊 OceanVista — Ocean Data Visualization System

> **An interactive web-based 3D ocean visualization platform for integrating, exploring, and analyzing ocean model data and in-situ observations.**

OceanVista is a web-based 3D ocean data visualization and analysis platform designed to bring together **numerical ocean model outputs** and **in-situ observations** such as **Argo Floats, Gliders, CTD, BGC, Moorings, and HF Radar** in a single interactive environment.

The platform enables users to visualize ocean parameters across **latitude, longitude, depth, and time**, making complex oceanographic datasets easier to understand and analyze.

---

## 🌊 Project Overview

India has a vast coastline and Exclusive Economic Zone (EEZ) that requires continuous monitoring of ocean conditions.

Organizations such as **INCOIS** generate large volumes of oceanographic data from:

- 🌐 Numerical Ocean Models
- 🛰️ Argo Floats
- 🤿 Underwater Gliders
- 🧪 CTD Observations
- 🧬 BGC Measurements
- ⚓ Moorings
- 📡 HF Radar

These datasets can contain information about temperature, salinity, currents, chlorophyll, dissolved oxygen, depth, and other ocean parameters.

However, these datasets are often available in different formats and sources, making integrated visualization and comparison difficult.

### OceanVista solves this problem by providing:

**One platform → Multiple data sources → Interactive 3D visualization → Analysis**

---

# 🎯 Objectives

The main objectives of OceanVista are:

- Integrate heterogeneous oceanographic datasets.
- Provide platform-independent web-based visualization.
- Visualize ocean data in an interactive 3D environment.
- Display observations together with model outputs.
- Enable depth-wise ocean exploration.
- Provide time-based visualization and animation.
- Allow users to upload their own datasets.
- Support scientific comparison between observations and model data.
- Provide charts and statistical analysis.
- Make complex ocean data easier to interpret.

---

# 🚀 Key Features

## 🌍 Interactive 3D Ocean Globe

OceanVista provides an interactive 3D Earth visualization where users can explore ocean regions.

Users can:

- Rotate the globe.
- Zoom into ocean regions.
- Explore observation locations.
- Select variables.
- Interact with observation markers.

---

## 📍 Argo Float Visualization

Argo Float observations can be displayed directly on the 3D globe.

Each observation can contain information such as:

- Float ID
- Latitude
- Longitude
- Depth
- Temperature
- Salinity
- Dissolved Oxygen
- Observation time
